<tasks>
<task id="07-01-01">
  <title>Implement SSRF-Safe HTTP Client with DNS Pre-Resolution and IP Socket Pinning</title>
  <read_first>
    - backend/app/detection/url_parser.py
    - .planning/REQUIREMENTS.md
  </read_first>
  <action>
    Create backend/app/intelligence/ssrf_client.py implementing SSRFSafeClient.
    - Pre-resolves target hostname via socket.getaddrinfo.
    - Validates all resolved IPv4/IPv6 addresses against forbidden subnets (RFC 1918 private subnets, loopback 127.0.0.0/8 & ::1, link-local 169.254.0.0/16 & fe80::/10, cloud metadata 169.254.169.254, carrier-grade NAT 100.64.0.0/10, test networks).
    - Pins the validated IP directly in the HTTP connection transport with Host header and SNI hostname extension to prevent DNS rebinding (TOCTOU) attacks.
    - Explicitly validates redirect targets (Location header) step-by-step against SSRF rules rather than naively following redirects.
    - Restricts protocols strictly to http and https.
  </action>
  <acceptance_criteria>
    - SSRFSafeClient blocks attempts to connect to 127.0.0.1, localhost, 10.x, 192.168.x, 172.16.x, and 169.254.169.254 with SSRFProtectionError
    - Pins the resolved IP address to prevent DNS rebinding
    - Validates redirect locations with step-by-step SSRF inspection
  </acceptance_criteria>
</task>
