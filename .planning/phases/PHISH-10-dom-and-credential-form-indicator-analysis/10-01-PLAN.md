<task id="10-01-01">
  <title>Implement Privacy-Preserving DOM Signal Extractor</title>
  <read_first>
    - extension/src/shared/types.ts
    - backend/app/detection/dom_evaluator.py
  </read_first>
  <action>
    Create extension/src/content/observer.ts implementing DOMSignalExtractor.
    - Inspects structural DOM elements:
      - Password input presence (input[type="password"]).
      - Login forms (forms containing password or username/email inputs).
      - Form action origin comparison (flags form action targeting an origin different from window.location.origin).
      - Form action IP destination (flags form action destination whose hostname is an IP address).
      - Hidden iframes count (iframes with display: none, visibility: hidden, opacity: 0, or width/height <= 1px).
      - Third-party script/resource ratio.
    - STRICT PRIVACY GUARANTEE: Never collect, inspect, or transmit input values, passwords, cookies, or auth tokens.
  </action>
  <acceptance_criteria>
    - DOMSignalExtractor produces typed DOMSignals matching shared/types.ts
    - Accurately detects cross-origin form action destinations
    - Accurately detects form action targeting IP addresses
    - Accurately counts hidden iframes
    - Guarantees zero secret collection
  </acceptance_criteria>
</task>
