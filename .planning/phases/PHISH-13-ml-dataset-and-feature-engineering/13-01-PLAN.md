<task id="13-01-02">
  <title>Implement Leakage-Free Domain Grouped Splitter</title>
  <read_first>
    - ml/src/dataset.py
  </read_first>
  <action>
    Create ml/src/splitters.py implementing `DomainGroupedSplitter`.
    - Group URLs by their `registered_domain` (eTLD+1).
    - Partition dataset into Train (70%), Validation (15%), and Holdout Test (15%) splits.
    - Guarantee zero domain overlap: `set(train_domains) & set(test_domains) == 0`.
    - Provide a validation function that asserts zero leakage between splits.
  </action>
  <acceptance_criteria>
    - Grouped split strictly partitions by domain without leaking samples across splits
    - Validates split distribution and class balance
  </acceptance_criteria>
</task>

<task id="13-01-03">
  <title>Implement 34-Feature Extraction Pipeline for ML</title>
  <read_first>
    - backend/app/detection/features.py
    - backend/app/detection/url_parser.py
  </read_first>
  <action>
    Create ml/src/features.py implementing `URLFeatureTransformer` (compatible with Scikit-learn BaseEstimator / TransformerMixin).
    - Extracts all 34 numeric features matching `backend/app/detection/features.py`:
      - Lexical lengths (url, host, path, query)
      - Delimiter counts (dots, hyphens, slashes, etc.)
      - Structural metrics (subdomains, IP host, punycode, high risk TLD, ports)
      - Shannon entropy (url, host, path)
      - Statistical character ratios (digits, vowels, consonants, consecutive consonants)
      - Suspicious credential keywords and brand positions
    - Exposes `feature_names` property with exact 34 names.
    - Returns 2D float64 NumPy array or Pandas DataFrame without NaN/Inf values.
  </action>
  <acceptance_criteria>
    - Extracts exactly 34 features with 100% parity with backend detection engine
    - Compatible with scikit-learn Pipeline
    - Zero NaNs or infinite values generated
  </acceptance_criteria>
</task>
